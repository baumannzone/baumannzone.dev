`:nth-child(2 of .active)` selecciona el segundo hijo de entre los que tienen la clase `.active`. La parte `of S` filtra primero los hermanos con un selector y después cuenta solo esos. Funciona en todos los navegadores modernos y sirve, por ejemplo, para hacer filas alternas que ignoren los elementos ocultos.

Mucha gente usa `:nth-child()` con fórmulas como `2n` o `even` y se queda ahí, sin saber que acepta un filtro.

## Lo básico: `:nth-child(An+B)`

Ya conoces la sintaxis clásica de `:nth-child()`:

- `:nth-child(2)`: Selecciona el segundo elemento.
- `:nth-child(2n)`: Selecciona todos los elementos pares (2º, 4º, 6º, 8º, ...).
- `:nth-child(2n+1)`: Selecciona todos los elementos impares (1º, 3º, 5º, 7º, ...).

Pero, ¿sabías que también puedes usar la sintaxis `of S` para hacer un prefiltro?

## ¿Qué es `of S`?

Cuando se especifica `of S`, la lógica `An+B` se aplica solo a los elementos que coinciden con la lista de selectores `S`.
Básicamente, esto significa que puedes prefiltrar los elementos hijos antes de que `An+B` entre en acción.

```css
tr:nth-child(2 of .active) {
  /* ... */
}
```

En este ejemplo, selecciona el segundo elemento que tenga la clase `.active`.
Dicho de otro modo, de entre todos los hijos con la clase `.active`, selecciona el segundo.

## El error común: `.active:nth-child(2)` no es lo mismo

Es fácil pensar que estas dos reglas hacen lo mismo:

```css
/* El segundo hijo, solo si además tiene .active */
li.active:nth-child(2) {
  /* ... */
}

/* El segundo de los hijos que tienen .active */
li:nth-child(2 of .active) {
  /* ... */
}
```

La primera cuenta **todos** los hermanos y después comprueba la clase: si el segundo hijo no tiene `.active`, no selecciona nada. La segunda cuenta **solo** los hermanos con `.active`, estén donde estén.

Con esta lista:

```html
<li class="active">A</li>
<li>B</li>
<li class="active">C</li>
```

`li.active:nth-child(2)` no selecciona nada, porque el segundo hijo es `B` y no tiene la clase. `li:nth-child(2 of .active)` selecciona `C`, el segundo de los que la tienen.

Tampoco es lo mismo que `:nth-of-type()`. Ese selector solo filtra por etiqueta (`li`, `p`, `tr`…), mientras que `of S` acepta cualquier selector: clases, atributos o pseudoclases como `:not()`.

## Caso práctico: lista con elementos ocultos

Imagina que tienes seis elementos en una lista, pero dos están ocultos con el atributo `hidden`.

```html
<li>Elemento 1</li>
<li hidden>Elemento 2</li>
<li>Elemento 3</li>
<li>Elemento 4</li>
<li hidden>Elemento 5</li>
<li>Elemento 6</li>
```

Si usas el clásico `:nth-child(even)`:

```css
li:nth-child(even) {
  background-color: violet;
}
```

<Demo1 />

Se resaltarán los elementos en las posiciones **3** y **4** de la lista, es decir, los elementos **4** y **6** del HTML.
Esto ocurre porque incluso los elementos ocultos se tienen en cuenta al contar.

No es el resultado que esperarías si lo que quieres es **resaltar cada segundo elemento visible**.

## Entra en escena `of S`

Para solucionar este problema, puedes usar `of :not([hidden])`:

```css
li:nth-child(even of :not([hidden])) {
  background-color: violet;
}
```

<Demo2 />

Cronología:

1. Crea una lista de todos los elementos `<li>` que están visibles: el 1, el 3, el 4 y el 6.
2. Aplica `even` a esa nueva lista: el segundo y el cuarto.

Boom. Ahora sí: se resaltan los elementos **3** y **6**, que son el segundo y el cuarto de los visibles, y los `hidden` no cuentan.

## Soporte en navegadores

La sintaxis `of S` funciona en Chrome y Edge desde la versión 111, en Firefox desde la 113 y en Safari desde la 9. Desde mayo de 2023 está disponible en todos los navegadores modernos, y desde noviembre de 2025 es _Baseline ampliamente disponible_: la puedes usar sin miedo.

## Curiosidades

- Safari fue el primero en implementar esta sintaxis, en 2015 (iOS y macOS). El resto de navegadores tardaron casi ocho años.
- Esta sintaxis también es compatible con `:nth-last-child()`.
- La especificidad de `:nth-child(… of S)` es la de una pseudoclase más la del selector más específico de `S`. Por ejemplo, `:nth-child(2 of #menu li)` pesa como un id, no como una simple pseudoclase.
