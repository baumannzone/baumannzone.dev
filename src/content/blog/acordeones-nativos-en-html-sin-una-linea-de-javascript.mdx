Para crear un acordeón sin JavaScript, envuelve cada sección en un `<details>` y pon el título dentro de un `<summary>`. El navegador se encarga de abrirlo, cerrarlo y hacerlo accesible con teclado. Y si quieres que solo haya una sección abierta a la vez, dales a todos el mismo atributo `name`.

Nada de instalar otro paquete de npm que te rompa el proyecto en dos meses.

## Cómo crear un acordeón con `<details>` y `<summary>`

Por defecto, cada `<details>` se puede abrir de forma independiente. Esto es genial si quieres permitir que se expandan múltiples secciones a la vez:

```html
<details>
  <summary>HTML</summary>
  <p>Es el lenguaje de marcado base para cualquier página web.</p>
</details>
<details>
  <summary>CSS</summary>
  <p>
    Sirve para dar estilo a los elementos, desde colores hasta layouts
    complejos.
  </p>
</details>
<details>
  <summary>JavaScript</summary>
  <p>Permite añadir interactividad, lógica y manipulación del DOM.</p>
</details>
```

Este código genera un acordeón con tres secciones y cada una se despliega de forma independiente, sin afectar a las demás.

<Demo1 />

Si quieres que una sección aparezca abierta al cargar la página, añádele el atributo `open`:

```html
<details open>
  <summary>HTML</summary>
  <p>Esta sección empieza abierta.</p>
</details>
```

Esto funciona genial y es la mejor manera de hacer un componente de acordeón con HTML nativo. Pero en algunos casos, vas a necesitar que solo una sección esté abierta a la vez.

## Cómo hacer que solo una sección esté abierta

Si quieres que solo una sección esté abierta a la vez, tenemos dos opciones:

1. **Usar HTML** (opción nativa): un atributo controla el estado de los acordeones. 🏆
2. **Usar JavaScript** (meh): un script cierra los demás `<details>` cuando uno se abre.

### Opción HTML: el atributo `name`

La solución nativa (y poco conocida) es usar el atributo `name`. Si todos los `<details>` tienen el mismo `name`, solo uno puede estar abierto a la vez.

Este comportamiento recuerda al de los `<input type="radio">`: dentro de un mismo grupo, solo uno puede estar activo.

El ejemplo anterior se puede reescribir así:

```html
<details name="faq">
  <summary>¿Cómo reinicio mi contraseña?</summary>
  <p>Haz clic en “olvidé mi contraseña” como todo el mundo.</p>
</details>

<details name="faq">
  <summary>¿Puedo usar mi cuenta en varios dispositivos?</summary>
  <p>Sí, aunque tu gato probablemente también lo está usando sin que sepas.</p>
</details>

<details name="faq">
  <summary>¿Qué pasa si borro mi cuenta?</summary>
  <p>Pasas al siguiente plano existencial digital. No hay vuelta atrás.</p>
</details>
```

<Demo2 />

El atributo `name` en `<details>` funciona en Chrome y Edge desde la versión 120, en Safari desde la 17.2 y en Firefox desde la 130. En un navegador antiguo no se rompe nada: simplemente se pueden abrir varias secciones a la vez.

### Opción JavaScript

Si necesitas algo que `name` no cubre, como guardar qué sección está abierta en `localStorage` o dar soporte a navegadores muy antiguos, puedes usar JavaScript. Aquí tienes un ejemplo sencillo:

```js
const allDetails = document.querySelectorAll("details");

allDetails.forEach((targetDetail) => {
  targetDetail.addEventListener("toggle", () => {
    if (!targetDetail.open) return;

    allDetails.forEach((detail) => {
      if (detail !== targetDetail) detail.open = false;
    });
  });
});
```

Uso el evento `toggle` en vez de `click` porque salta cuando el `<details>` cambia de estado, da igual si ha sido con el ratón, con el teclado o desde código.

## Dale estilo a tus `<summary>`

Ahora que tus `<details>` se comportan como tú quieres, puedes ir un paso más allá y darles un toque visual simpático.

CSS te permite modificar el icono que aparece al lado de `<summary>` usando el pseudo-elemento `::marker`.

Por defecto, el icono es un triángulo (⏵), pero puedes cambiarlo a cualquier cosa que te guste.

```css
summary::marker {
  content: "🙈";
}

[open] summary::marker {
  content: "🙉";
}
```

## Accesibilidad

Los elementos `<details>` y `<summary>` son semánticamente accesibles por defecto. No necesitas hacer nada especial con JavaScript.

El elemento `<summary>` es focusable, se puede activar con `Enter` o `Space`, y los lectores de pantalla anuncian si la sección está expandida o contraída.

Como siempre: **testea**. Con teclado, con lectores de pantalla, y si tienes amigos, con alguien que no tenga tus mismos privilegios visuales o de motricidad. El HTML hace mucho por ti, pero tú tienes que poner algo también.

## Conclusión

Los elementos `<details>` y `<summary>` son herramientas potentes, accesibles y que muchas veces pasamos por alto. Para acordeones simples, no necesitas JavaScript, ni React, ni MUI, ni librerías de 20 KB. Solo HTML y un poco de CSS.

Y si quieres limitar su comportamiento a uno abierto a la vez, puedes usar el atributo `name` para conseguirlo de forma elegante.

No subestimes el poder de lo nativo. La próxima vez que necesites un acordeón o un panel desplegable, ya sabes: empieza por lo simple. Lo demás, si hace falta, ya vendrá.
