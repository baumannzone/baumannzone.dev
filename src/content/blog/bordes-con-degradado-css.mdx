Con `border` solo puedes pintar un borde de un color. Si lo quieres multicolor o con una imagen, necesitas `border-image`.

Todos los ejemplos parten de esta caja:

```css
.box {
  width: 200px;
  height: 100px;
  border-style: solid;
  border-width: 10px;
}
```

```html
<div class="box"></div>
```

## Bordes con imágenes

`border-image` necesita dos cosas: la imagen (`border-image-source`) y cómo trocearla (`border-image-slice`).

```css
.border-image {
  border-image-source: url(/image/path/file.png);
  border-image-slice: 1;

  /* O con el shorthand:
   * border-image: url(/image/path/file.png) 1;
   */
}
```

```html
<div class="box border-image"></div>
```

### Qué hace `border-image-slice`

`border-image-slice` corta la imagen en nueve trozos, como un tres en raya. Las cuatro esquinas van a las esquinas del borde, los cuatro lados se estiran a lo largo de cada lado del borde y el centro se descarta.

El número es la distancia del corte, en píxeles de la imagen, medida desde cada lado. Con `1`, cada lado del borde usa solo la franja de 1 px del borde de la imagen, estirada. Por eso no ves la foto entera en el borde, solo los colores de sus bordes:

## Bordes con degradados

Un degradado de CSS también es una imagen, así que puedes usarlo en `border-image`. Hay tres tipos: `linear-gradient`, `radial-gradient` y `conic-gradient`.

Aquí `border-image-slice: 1` es justo lo que quieres. El degradado se genera al tamaño de la caja, y cada lado del borde toma la franja exterior del degradado. El resultado es el mismo color que verías en el borde del degradado si lo pusieras de fondo.

En cada demo te dejo el degradado como borde y como fondo, para que compares.

### Linear gradient

En `linear-gradient` puedes indicar el ángulo. Por defecto es `to bottom` (180 grados): el degradado va de arriba abajo. Aquí uso 45 grados, para que los colores vayan en diagonal.

```css
.linear-gradient {
  border-image: linear-gradient(45deg, red, lime, blue) 1;
}
```

```html
<div class="box linear-gradient"></div>
```

<BorderWithLinearGradient />

### Radial gradient

```css
.radial-gradient {
  border-image: radial-gradient(red, cyan) 1;
}
```

```html
<div class="box radial-gradient"></div>
```

<BorderWithRadialGradient />

El degradado radial empieza en el centro de la caja. Como el borde solo usa los bordes exteriores, casi no queda rojo: lo que ves es sobre todo `cyan`.

### Conic gradient

```css
.conic-gradient {
  border-image: conic-gradient(lime, fuchsia, cyan) 1;
}
```


## Bordes con degradado y esquinas redondeadas

`border-image` tiene una limitación: ignora `border-radius`. No es un fallo de ningún navegador, lo dice la especificación.

Para tener un borde con degradado y esquinas redondeadas, el truco es no usar `border-image`. En su lugar, pintas dos fondos:

```css
.rounded-gradient {
  border: 10px solid transparent;
  border-radius: 16px;
  background:
    linear-gradient(#fff, #fff) padding-box,
    linear-gradient(45deg, red, lime, blue) border-box;
}
```

- El primer fondo es un color liso (blanco, el de tu caja) que llega hasta el `padding-box`, es decir, hasta el borde sin incluirlo.
- El segundo es el degradado, que llega hasta el `border-box` y asoma por debajo del borde transparente.

Como son fondos, respetan `border-radius`:

<RoundedGradientBorder />

La única pega es que el interior no puede ser transparente: tienes que repetir el color de fondo de la caja.

## Soporte

`border-image` funciona en todos los navegadores modernos desde hace años. Es [Baseline ampliamente disponible](https://caniuse.com/border-image), así que puedes usarlo sin miedo.
