Sí, se puede hacer un juego solo con HTML y CSS, sin una línea de JavaScript. En el juego del unicornio, `:hover` y el combinador `~` detectan si tocas una pared, `clip-path` da forma a la mazmorra, una animación con retraso decide cuándo has ganado y `attr()` pone el texto de la pantalla final. Más abajo puedes jugarlo y te explico cada pieza.

CSS no es un lenguaje de programación como JavaScript, y a nadie se le ocurriría crear un juego con él. No es muy sensato. Esa es justo la parte divertida: igual que cuando hacemos dibujos con CSS en Twitch, se trata de experimentar y exprimir el lenguaje hasta ver dónde están sus límites.

## Antonio, el unicornio

[Antonio](https://youtu.be/x2kLLNFh-1k) es el nombre con el que la comunidad, a través de una encuesta, bautizó al unicornio que fue creado durante un streaming en mi canal de Twitch usando solo HTML y CSS.

Antonio buscaba una vida llena de alegría y color. Le gustaba explorar el mundo y dar largos paseos por las nubes. Contemplar las estrellas y sentir la brisa en la cara era algo que le encantaba.

En uno de esos paseos, se despistó y se desorientó. De repente no sabía dónde estaba, no entendía qué estaba pasando. Cuando se dio cuenta, vio que estaba atrapado en una mazmorra de la que no sabía salir.

## Objetivo del juego

El objetivo del juego es guiar al unicornio hasta el final de la mazmorra, usando el _ratón_ de tu ordenador. El único inconveniente es que las paredes de la mazmorra están malditas y el unicornio morirá si las toca. Estoy seguro de que no quieres que la culpa de la muerte del unicornio recaiga sobre ti.

## Controles del juego

Para jugar al _juego del unicornio_ solo necesitas el ratón, una mente fría y un poco de destreza. En cuanto pongas el cursor sobre el triángulo verde, la pantalla empezará a moverse y el juego habrá empezado. Recuerda, no se pueden tocar las paredes.

El juego depende de `:hover`, así que con una pantalla táctil no se puede jugar. Necesitas un ordenador con ratón.

## HTML

La estructura HTML del juego es la siguiente:

```html
<div class="game">
  <div class="dungeon">
    <div class="dungeon-wall-left"></div>
    <div class="dungeon-wall-right"></div>
    <div
      class="n00b"
      data-text="El pobre unicornio ha muerto por tu culpa ☠️ ☠️ ☠️"
    ></div>
    <div
      class="gg"
      data-text="¡Bien hecho! 🎉 El unicornio ha escapado 🌈 🌈 🌈"
    ></div>
  </div>
</div>
```

- `.dungeon`: la mazmorra. Le da la perspectiva 3D al juego para simular un efecto de _punto de fuga_.
- `.dungeon-wall-left` y `.dungeon-wall-right`: las paredes malditas.
- `.n00b`: la pantalla de derrota. Se ve cuando tocas una pared.
- `.gg`: la pantalla de victoria. Se ve cuando el unicornio consigue salir de la mazmorra.

## CSS

Para crear el juego usaremos, entre otras cosas:

- `clip-path` para darle la forma a las paredes.
- `transform` para el desplazamiento y efecto 3D.
- `animation` y `@keyframes` para mover y animar los elementos.
- Pseudo-elementos y funciones de CSS. 🤯

Las paredes de la mazmorra usan `background-image` con SVG para simular los ladrillos, que hemos recortado y dado forma con `clip-path`.

El juego comienza cuando pones el ratón en el triángulo verde: las paredes empiezan a moverse, [el cursor](https://baumannzone.github.io/cursores-css/) se convierte en un unicornio y se inicia la animación que muestra la pantalla de victoria.

### Cómo se pierde

Si tocas una pared, se muestra la pantalla de derrota. Para eso uso `:hover` en las paredes y el combinador de hermanos `~`, que selecciona los elementos que van después en el mismo padre:

```css
/* Si tocas una pared, aparece la pantalla de derrota */
.dungeon-wall-left:hover ~ .n00b,
.dungeon-wall-right:hover ~ .n00b,
.n00b:hover {
  display: block;
  z-index: 10;
}
```

Por eso en el HTML `.n00b` va después de las paredes: `~` solo mira hacia delante. Y `.n00b:hover` hace que, una vez muerto el unicornio, la pantalla se quede mientras tengas el ratón encima.

### Cómo se gana

El truco es el tiempo. La animación que muestra la pantalla de victoria tiene 5 segundos de _delay_, lo mismo que tardan las paredes en recorrer la mazmorra. Si aguantas esos 5 segundos sin tocar nada, has llegado al final.

```css
/* Mueve las paredes durante 5 segundos */
.dungeon:hover .dungeon-wall-left,
.dungeon:hover .dungeon-wall-right {
  animation: move-walls 5s linear;
}

/* Muestra la pantalla de victoria después de 5 segundos */
.dungeon:hover .gg {
  animation: show-gg 0s 5s linear forwards;
}
```

### El texto de las pantallas

Al finalizar la partida verás una pantalla con texto, tanto si ganas (`.gg`) como si pierdes (`.n00b`). El texto lo sacamos del atributo `data-text` de cada capa usando la función CSS `attr()`. Sinceramente, ¡me parece superpotente esta función de CSS!

```css
.gg::after,
.n00b::after {
  /* ... */
  content: attr(data-text);
}
```

Y hoy lo es todavía más: en Chrome, desde la versión 133, `attr()` ya no se limita a `content`. Funciona en cualquier propiedad y con tipos, por ejemplo `width: attr(data-size px)`.
